# TEDDY-XMD ULTRA Frontend

Premium static frontend for **TEDDY-XMD ULTRA — Powered by Teddy Tech**.

## Deploy on Vercel

1. Upload this folder to GitHub.
2. Open Vercel and import the repository.
3. Keep the project as a static site.
4. No build command is required.
5. Deploy.

You can also drag the project into a Vercel deployment workflow.

## Edit links

Open `script.js`.

At the top you will find:

- `servers` — Server 1 to Server 5
- `github` — GitHub repository
- `socials` — WhatsApp, WhatsApp Group, WhatsApp Channel, Telegram Group, Telegram Channel and Contact Developer

Server 1–5 currently all use:

https://teddyxmdultraminifinal-14c420cbedd9.herokuapp.com/

Replace them later with your actual server URLs.

Replace:
- `https://wa.me/YOUR_NUMBER`
- `https://t.me/YOUR_TELEGRAM_GROUP`
- `https://t.me/YOUR_TELEGRAM_CHANNEL`
- `https://wa.me/YOUR_DEVELOPER_NUMBER`

with your real links.
